# DrorWhey

יומן אימונים אישי: תוכנית דחיפה/משיכה, רישום לפי סטים, שיאים, גרפים, טיימר מנוחה ולוח שנה.

## התקנה בטלפון
1. פותחים את האתר בדפדפן: Safari באייפון, Chrome באנדרואיד.
2. **אייפון:** כפתור השיתוף ← "הוסף למסך הבית". **אנדרואיד:** תפריט ⋮ ← "התקן אפליקציה" או "הוסף למסך הבית".
3. מאז פותחים רק מהאייקון במסך הבית. באייפון, לאפליקציה שבמסך הבית יש אחסון נפרד מ-Safari.

## נתונים
הכול נשמר רק במכשיר, ושום דבר לא נשלח לשרת. בלשונית "התקדמות" ← "שמור גיבוי" שומרים קובץ גיבוי, ומומלץ לעשות את זה פעם בשבועיים. "שחזר מגיבוי" מחזיר את הנתונים מהקובץ.

## פיתוח
האתר נבנה מהקובץ `app/training-app.html` עם הפקודה `python app/build_web.py`. זה אותו קוד שמשמש את גרסת claude.ai, והבנייה מוסיפה שכבת אחסון מקומית, Service Worker לעבודה בלי חיבור, ו-manifest.
